# Mensagens que os botões enviam ao CubeSat pelo módulo LoRa.
# Usadas pelo dashboard Python (PC e Raspberry) e pelos botões do Node-RED do
# Raspberry.
#
# Formato: uma linha por botão,   NOME = mensagem
#   - {SETPOINT} é trocado pelo setpoint de atitude em hexadecimal, 4 dígitos,
#     big-endian (16 -> 0010, 90 -> 005A, 300 -> 012C);
#   - o \r\n do fim da linha é colocado sozinho;
#   - mensagem vazia = botão não envia nada (mostra "não configurado");
#   - linhas começando com # são comentários.
#
# Depois de mudar:
#   - dashboard Python: vale no próximo clique (não precisa reabrir);
#   - Raspberry: rode  raspberry/enviar_para_rasp.sh  no PC (copia este arquivo
#     para o dashboard de lá e gera o fluxo do Node-RED com estas mensagens).
